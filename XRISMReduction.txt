
With HEASOFT and CalDB installed:

- Data will have observation ID as top directory, e.g. 000125000/ (from now, datadir)
    - Pipeline scripts must be run in a directory that contains this directory

Reprocessing:

DATADIR = 000125000

- In the directory above datadir run:
    
    xapipeline indir=$DATADIR outdir=$DATADIR_rsl_reproc steminputs=xa$DATADIR stemoutputs=DEFAULT entry_stage=1 exit_stage=3 instrument=resolve verify_input=no create_ehkmkf=no calc_pointing=yes calc_optaxis=yes calc_gtilost=no calc_adrgti=no calc_mxsgti=no rsl_gainfile=CALDB calmethod=FE55 linetocorrect=MnKa seed=650504 numevent=1000 minevent=200 extraspread=40 spangti=no 

    7z a $DATADIR_rsl_logs.7z *.log

    rm *.log

    cd $DATADIR_rsl_reproc

    rm *.hk

    gzip *

    cd ..

- Then

    xapipeline indir=$DATADIR outdir=$DATADIR_xtd_reproc steminputs=xa$DATADIR stemoutputs=DEFAULT entry_stage=1 exit_stage=3 instrument=xtend verify_input=no create_ehkmkf=no calc_pointing=yes calc_optaxis=yes seed=650504

    7z a $DATADIR_xtd_logs.7z *.log

    rm *.log

    cd $DATADIR_xtd_reproc

    rm *.hk

    gzip *

    cd ..

- Then

    mkdir analysis

    cp $DATADIR_xtd_reproc/*_cl.evt.gz analysis/
    cp $DATADIR_rsl_reproc/*_cl.evt.gz analysis/

    cp $DATADIR_rsl_reproc/xa$DATADIR.ehk.gz $DATADIR_rsl_reproc/xa$DATADIRrsl_px1000_exp.gti.gz $DATADIR_xtd_reproc/xa$DATADIRxtd_p031100010.bimg.gz analysis/

- Run PSP limit check to see if the unscreened count rate exceeds the psp limit

    rslbratios infile=xa$DATADIRrsl_p0px1000_uf.evt.gz filetype=uf outroot=rsl$DATADIR_ufbr
